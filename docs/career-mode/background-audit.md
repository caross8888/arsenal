# 커리어 오버레이 배경 점검 — 2026-10-14

## 이번 수정

선택 카드의 불투명도는 유지하고, 인터뷰실의 중앙 스폰서 벽과 의자를 크림색·웜그레이·토프색으로 바꿨다. 회색기가 강하고 평평한 구형 그림 다섯 장(라커룸, 식단, 공항, SNS, 학업)을 이적시장과 같은 따뜻한 목재·크림색 도트 화풍으로 다시 제작했다. 각 그림은 모바일용 세로 구도로 만들고 실제 이벤트 UI에서 확인한다. 주장·부주장은 같은 라커룸을, 대회 소집은 대표팀 차출과 같은 공항을 공유한다.

## 그림 배경이 없는 오버레이

아래 화면은 코드상 배경 이미지가 빠진 상태다. 이미지 로딩 오류가 아니라 현재 CSS 색·그라데이션·발광·카드 연출을 사용한다. 이번에는 목록만 정리했고 새 배경을 자동으로 추가하지 않았다.

| 화면 | 렌더링 함수 | 현재 배경 |
|---|---|---|
| 입단 환영 | `crWelcome` | CSS 배경 + 선수 아바타 |
| 프로 계약·이적 계약·재계약 서명 | `crProShow` | CSS 배경 + 계약서 |
| 상무 최종 선발·전역 복귀 | `crMilitaryAnnouncement` | 완료 발표 CSS + 구단 문장 |
| 발롱도르 수상 | `crBallonShow` | CSS 배경 + 트로피 + 종이꽃 |
| 별도 월드컵 우승 축하 | `crWorldCupShow` | CSS 배경 + 월드컵 트로피 + 종이꽃 |
| 별도 아시안게임·올림픽 메달 결과 | `crMilitaryResultExtra` | CSS 배경 + 메달 |
| 잠재력 평가 | `crScoutShow` | CSS 배경 + 평가 카드 |
| 재능 개화 | `crBloomShow` | CSS 배경 + 특성 카드·발광 |
| 타고난 재능·새 특성 선택 | `crResult`의 `cr-tov` | CSS 배경 + 특성 카드 |
| 뉴스·SNS·커뮤니티 상세 | `crReactionHtml` | CSS 배경 + 기사·게시글 패널 |

대회 결과 화면 내부의 대표팀 반응 상세도 독립적인 그림 배경 없이 패널로 표시한다. 같은 오버레이 시스템을 쓰는 Who Am I 완료 연출은 커리어 모드 목록에서 제외했다. 시즌 목표·훈련 방향 등 준비 페이지 항목과 부상 선택은 전체 화면 오버레이가 아니므로 별도로 센다.
