# 소꿉친구 관계 시스템 · 첫 구현

새 커리어에서 시작 국적에 맞는 고정 소꿉친구 한 명을 생성한다. 동아시아(KOR/JPN), 남미(BRA/ARG), 아프리카(NGA), 서구권(그 외 현재 지원국)의 승인된 4종 캐릭터를 사용한다. 이름은 임시 설정이며 한국은 서윤, 일본은 유이, 남미는 루시아, 아프리카는 아마라, 서구권은 에밀리다. 출신 국가를 이적해도 소꿉친구는 바뀌지 않는다.

## 기존 플레이에 들어가는 위치

- 매 시즌 **관계 이벤트 1개 → 기존 시즌 이벤트·훈련 준비 → 시즌 진행 → 결과·이적시장** 순서다. 관계 선택으로 대표팀 차출·임대·성장 이벤트를 대체하지 않는다.
- 첫 유스 준비: 휴대폰 모양 오버레이에 소꿉친구의 메시지가 차례로 도착한다. 플레이어가 답장을 고르면 상대의 응답을 받은 뒤 시즌 준비로 넘어간다. 메신저 대화는 모두 같은 UI를 쓴다.
- 매년 하나의 관계 선택을 제공한다. 큰 사건이 없는 해에는 나이와 관계 상태에 맞는 일상 대화나 만남이 나온다. 친구·연인·부부 대화를 구분하며, 헤어진 뒤에는 다정한 연락 대신 과거를 정리하는 짧은 독백을 쓴다. 복무 중에는 연락만 가능한 상황에 맞춘다.
- 수락한 만남은 전신 캐릭터와 장소 배경이 있는 장면으로 이어진다. 도착·서로의 대화·끝인사·귀가까지 마무리하고, 큰 사건은 선택 전 도입과 선택 후 분기 대화를 보여준다. 중간에는 시즌 준비 버튼을 표시하지 않으며 마지막 마무리 장면을 읽은 뒤에만 최초 선택을 저장한다. 대사를 넘기는 것은 추가 연간 선택을 소비하지 않는다. 짧은 연락은 답장 뒤에 끝난다.
- 첫 1군 공식 출전은 경기 시점의 별도 특별 사건이다. 첫 실제 출전 전에 관중석을 훑어보고 소꿉친구를 발견한다. 경기 기록 한 건을 반영한 직후 연락을 받고, 만남을 선택하면 즉시 경기장 출구 장면으로 이어진다. 다음 시즌 준비로 미루지 않으며 건너뛰기에서도 생략하지 않는다.
- 결과 화면에는 짧은 시즌 노트를 유지하며, 은퇴카드에는 상대 초상과 관계, 결혼했으면 배우자와 결혼 연도를 표시한다.

큰 관계 사건은 최대 5개이며 사건 사이 최소 2세 차이를 둔다. 첫 프로 출전 당일 만남 → 21세 이후 외출 → 23세 이후 고백 → 실제 해외 이적 후 관계 이야기(해당할 때만) → 28세 이후 프로포즈. 이 제한은 매년의 일상 선택과 별개다. 나이는 최초 허용 조건이며 해당 나이에 반드시 발생하지는 않는다. 복무 중에는 큰 관계 사건을 미룬다. 일반 관계 선택은 시즌 준비 나이를 `prepAge`에 저장해 같은 시즌에 다시 나오지 않으며, 첫 경기 사건은 이 값을 소비하지 않는다.

첫 프로 출전은 실제 확정된 시즌 기록에 `youth:false`, `apps>0`이 있을 때만 인정한다. 이 기록은 시뮬레이터의 공식 리그 출전이며 친선전·유스·벤치 대기는 포함하지 않는다. 부상 처리 전에는 두 부상 선택에서 공통으로 보장되는 출전 기록만 조건으로 사용한다. 첫 경기 장면 완료 여부는 서명된 토큰에 보존하며, 만남 장면을 끝내야 사건을 소비한다. 미완료 상태에서 다음 시즌으로 넘어갈 수 없다. 새로고침하면 경기 후 연락부터 이어간다. 해외 이적은 `nextSeason`에서 선택한 제안으로 실제 구단 국가가 변경됐을 때만 기록한다. 제안 생성·열람, 거절, 국내 이적은 조건을 충족하지 않는다.

## 상태와 범위

`C.relationship`은 기존 암호화 커리어 토큰에 포함된다. 상대, 관계 상태, 내부 호감도, 처리한 사건, 마지막 큰 사건 나이, 연간 선택 완료 나이와 최근 일상 선택, 실제 해외 이적 여부, 결혼 나이를 저장한다. 숨은 호감도는 응답에 공개하지 않는다. 고백 거절 후에는 친구로 남으며 자동으로 결혼하지 않는다. 장거리 관계 종료도 선택할 수 있다.

관계가 없는 구형 저장 데이터와 구형 은퇴카드는 그대로 읽으며 과거 연애를 만들어 넣지 않는다. 신규 커리어부터 적용한다. 관계 선택은 경기 난수에 영향을 주지 않으며 부상·승부차기 중간 저장에서도 한 번만 반영된다. 축구 기록이나 랭킹 점수에 관계 수치를 직접 가산하지 않는다. 기존 성장 이벤트를 유지하므로 관계 선택 자체가 성장 기회를 줄이지 않는다.

현장 대본은 `public/career/relationship-scenes.js`에 두며 일상 만남 6종과 큰 사건의 분기별 대화를 관리한다. 주인공과 상대가 번갈아 이야기하고 내레이션으로 시간의 흐름과 마무리를 보여준다. 같은 장소의 대사를 넘길 때 장면 전체를 다시 만들지 않는다.

메신저는 첫 연락·약속 잡기·짧은 안부에 사용한다. 만남 수락 뒤에는 전신 캐릭터와 실제 장소에서 대화를 보여준다. 고백·프로포즈·이적 후 대화도 장소 장면을 사용한다. 관중석·경기장 출구·카페·저녁 공원 4종 배경을 쓴다.

캐릭터의 얼굴과 체형 기준은 사용자가 승인한 `asia.png`, `south.png`, `africa.png`, `europe.png` 네 원본이다. 얼굴이 비슷해진 통합 생성 시트는 사용하지 않는다. 각 원본 한 장씩을 따로 참조해 배경을 제거한 `actor-{지역}-v3.png`를 연결하며, 각 파일에는 기존 기본·미소·데이트 세 모습이 들어 있다. 추가 `reactions-{지역}-v1.png`는 각 캐릭터의 데이트 의상을 유지한 차분함·웃음·쑥스러움·슬픔 네 표정/팔 자세를 가로 4칸으로 제공한다. 같은 만남 중 의상을 바꾸지 않고 대사에 맞춰 표정과 포즈를 지정한다. 일상복 장면은 기존 기본/미소 두 컷을 사용한다. 관중석에서는 미소 포즈, 일상복 만남에서는 기본/미소 포즈, 데이트와 큰 관계 사건에서는 해당 캐릭터의 데이트복과 네 가지 반응을 사용한다. 새 포즈를 만들 때도 원본 한 명씩만 참조하고 원본 얼굴과 비교해야 한다. 캐릭터를 여러 명 동시에 다시 생성해 외모를 통일하지 않는다.

별도 연애 후보, 출산·육아, 독립 스토리모드는 범위 밖이다. 기존 버전 1 저장에서 이미 지나간 데뷔는 당시 경기를 재생한 척하지 않고 예전의 준비 이벤트로 이어간다. 신규/아직 데뷔 전 커리어에서는 경기 시점 체크포인트를 사용한다.

테스트를 위해 `codex/relationship-event-sample` 브랜치 하나만 Vercel 자동 미리보기 대상으로 허용한다. 다른 작업 브랜치의 비활성 설정은 유지한다. 이 브랜치 한정 설정은 main 병합 전에 제거한다.

검증: `node scripts/test_career_relationship.mjs`.
