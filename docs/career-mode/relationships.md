# 소꿉친구 관계 시스템 · 첫 구현

새 커리어에서 시작 국적에 맞는 고정 소꿉친구 한 명을 생성한다. 동아시아(KOR/JPN), 남미(BRA/ARG), 아프리카(NGA), 서구권(그 외 현재 지원국)의 승인된 4종 캐릭터를 사용한다. 이름은 임시 설정이며 한국은 서윤, 일본은 유이, 남미는 루시아, 아프리카는 아마라, 서구권은 에밀리다. 출신 국가를 이적해도 소꿉친구는 바뀌지 않는다.

## 기존 플레이에 들어가는 위치

- 첫 유스 준비 화면: 소꿉친구와 자동으로 주고받은 짧은 메시지를 접을 수 있는 카드로 표시. 별도 답장 선택 없음.
- 일반 시즌: 기존 훈련·시즌 진행·결과·이적시장 순서 유지.
- 일반 관계 사건이 준비된 시즌: 일반 시즌 준비 이벤트 하나를 관계 선택으로 대체.
- 첫 1군 공식 출전만 경기 시점의 특별 사건으로 처리한다. 시즌 연출에서 첫 실제 출전 전에 관중석을 훑어보고 소꿉친구를 발견한다. 경기 기록 한 건을 반영한 직후 연락을 받고, 만남을 선택하면 즉시 경기장 출구 장면으로 이어진다. 다음 시즌 준비로 미루지 않는다. 시즌 건너뛰기·모션 줄이기에서도 이 사건은 생략하지 않는다.
- 대표팀 대회 차출과 임대 선택, 복무 중 시즌은 우선 유지하고 관계 사건은 미룬다.
- 결과 화면: 첫 실제 프로 출전 축하와 간헐적인 안부, 선택한 관계 사건의 답장을 기존 시즌 노트에 표시. 추가 팝업 없음.
- 은퇴카드: 관계와 상대 초상을 표시. 결혼했으면 배우자와 결혼 연도 표시.

관계 선택은 한 회차 최대 5개, 선택 사이 최소 2세 차이를 둔다. 첫 프로 출전 당일 만남 → 21세 이후 외출 → 23세 이후 고백 → 실제 해외 이적 후 관계 이야기(해당할 때만) → 28세 이후 프로포즈. 나이는 연애 시기를 조절하는 최초 허용 조건이며 그 나이에 반드시 발생하는 것은 아니다. 경기·이적 조건과 기존 필수 선택에 따라 늦어질 수 있다.

첫 프로 출전은 실제 확정된 시즌 기록에 `youth:false`, `apps>0`이 있을 때만 인정한다. 이 기록은 시뮬레이터의 공식 리그 출전이며 친선전·유스·벤치 대기는 포함하지 않는다. 부상 처리 전에는 두 부상 선택에서 공통으로 보장되는 출전 기록만 조건으로 사용한다. 첫 경기 장면 완료 여부는 서명된 토큰에 보존하며, 만남 장면을 끝내야 사건을 소비한다. 미완료 상태에서 다음 시즌으로 넘어갈 수 없다. 새로고침하면 경기 후 연락부터 이어간다. 해외 이적은 `nextSeason`에서 선택한 제안으로 실제 구단 국가가 변경됐을 때만 기록한다. 제안 생성·열람, 거절, 국내 이적은 조건을 충족하지 않는다.

## 상태와 범위

`C.relationship`은 기존 암호화 커리어 토큰에 포함된다. 상대, 관계 상태, 내부 호감도, 처리한 사건, 마지막 선택 나이, 실제 해외 이적 여부, 결혼 나이를 저장한다. 숨은 호감도는 응답에 공개하지 않는다. 고백 거절 후에는 친구로 남으며 자동으로 결혼하지 않는다. 장거리 관계 종료도 선택할 수 있다.

관계가 없는 구형 저장 데이터와 구형 은퇴카드는 그대로 읽으며 과거 연애를 만들어 넣지 않는다. 신규 커리어부터 적용한다. 관계 선택은 경기 난수에 영향을 주지 않으며 부상·승부차기 중간 저장에서도 한 번만 반영된다. 축구 기록이나 랭킹 점수에 관계 수치를 직접 가산하지 않는다. 다만 기존 성장 이벤트 일부를 대체하므로 전체 밸런스는 추후 실제 플레이 평가가 필요하다.

메신저는 첫 연락·약속 잡기·짧은 안부에 사용한다. 만남 수락 뒤에는 전신 캐릭터와 실제 장소에서 대화를 보여준다. 고백·프로포즈·이적 후 대화도 장소 장면을 사용한다. 관중석·경기장 출구·카페·저녁 공원 4종 배경을 쓴다.

캐릭터의 얼굴과 체형 기준은 사용자가 승인한 `asia.png`, `south.png`, `africa.png`, `europe.png` 네 원본이다. 얼굴이 비슷해진 통합 생성 시트는 사용하지 않는다. 각 원본 한 장씩을 따로 참조해 배경을 제거한 `actor-{지역}-v3.png`를 연결하며, 각 파일에는 기존 기본·미소·데이트 세 모습이 들어 있다. 관중석에서는 미소 포즈, 일반 만남에서는 기본 포즈, 데이트에서는 해당 캐릭터의 데이트복을 사용한다. 새 포즈를 만들 때도 원본 한 명씩만 참조하고 원본 얼굴과 비교해야 한다. 캐릭터를 여러 명 동시에 다시 생성해 외모를 통일하지 않는다.

별도 연애 후보, 출산·육아, 독립 스토리모드는 범위 밖이다. 기존 버전 1 저장에서 이미 지나간 데뷔는 당시 경기를 재생한 척하지 않고 예전의 준비 이벤트로 이어간다. 신규/아직 데뷔 전 커리어에서는 경기 시점 체크포인트를 사용한다.

테스트를 위해 `codex/relationship-event-sample` 브랜치 하나만 Vercel 자동 미리보기 대상으로 허용한다. 다른 작업 브랜치의 비활성 설정은 유지한다. 이 브랜치 한정 설정은 main 병합 전에 제거한다.

검증: `node scripts/test_career_relationship.mjs`.
