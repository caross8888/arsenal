# 관계 이벤트 샘플

프런트엔드만 동작하는 검토용 샘플. 실제 커리어 로직·선택 빈도·저장 데이터는 변경하지 않는다.

실행:

```sh
python3 -m http.server 8080 --directory arsenal-dashboard/public
```

브라우저에서 `http://localhost:8080/career/relationship-sample/`을 연다.

## 장면

- 15세 유스 합류 직후 소꿉친구의 연락과 답장. 첫 연락은 메신저 전용 화면으로, 받은 말풍선 → 선택한 내 답장 → 상대 후속 답장을 같은 대화 기록에 표시한다. 프로 계약으로 표현하지 않는다.
- 19세 첫 1군 공식 프로경기 실제 출전: 커리어 선택 → 기록 확인 → 관계 선택 → 답장.
- 23세 실제 해외 이적 완료 후 연인과 대화. 이미 연애 중이라는 독립된 미래 예시이며 앞의 두 이벤트만으로 연애가 시작되는 설정은 아니다.
- 접힌 조건 메뉴: 유스 출전, 1군 벤치 대기, 데뷔 후 다음 시즌, 해외 제안만 도착, 국내 이적 완료. 해당 조건에는 데뷔/해외 이적 관계 장면이 뜨지 않는다.

선택 횟수는 대사 선택만 계산한다. 장면 이동은 제외하며, 데뷔 시즌에는 커리어 1회와 관계 1회가 있다. 관계 수치는 메모리에만 두고 화면에는 관계 문구로 표시한다. 휴식과 다음 약속 잡기는 관계를 악화시키지 않는다.

## 범위와 후속 작업

서윤은 동아시아 소꿉친구의 임시 이름이다. 승인된 캐릭터 시트 원본을 복사하고 CSS로 초상 영역을 표시했다. 기존 커리어 배경을 임시 재사용한다. 실제 게임 통합, 전신 투명 애셋, 장소별 신규 배경, 나머지 세 캐릭터, 연애·결혼·출산 상태 모델은 포함하지 않는다.

이 샘플의 사건 조건은 검토용 자료를 사용한다. 실제 도입 시 서버가 확정한 1군 공식 출전 기록과 이적 전후 소속 국가에 연결하고, 데뷔 이벤트 소비 여부를 커리어 저장 상태에 기록해야 한다. 기존 시즌 이벤트 빈도는 아직 바꾸지 않았다.

검증:

```sh
node scripts/test_relationship_sample.mjs
```
