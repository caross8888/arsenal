# 급여 현실성 점검 — 2026-10-15

## 판정

현재 `_career_finance.js` 초안은 배포 및 기존 랭킹 카드 일괄 계산에 사용하지 않는다.
계약 유지/통화 계산/중복 적립 방지 테스트 통과는 실제 임금 수준 검증을 뜻하지 않는다.
이번 조사에서 상한 곡선, 성인 최저 급여, 구단 예산 대용으로 사용한 명성 값의 문제가 확인됐다.
이 문서는 현 모델의 점검 결과이며 보정 완료 보고서가 아니다.

## 비교 조건

- 모델 수치는 별도 표기가 없으면 26세, 최근 시즌 보정 없음, 기존 계약 협상 기준.
- 실제 선수에게 게임 OVR을 임의로 지정하지 않는다. OVR 입력 사례와 실제 선수 급여는
  각 구간의 규모/상한 점검용이며 동일 선수의 오차율이 아니다.
- 평균과 개인 주전 급여, 구단 전체 인건비와 선수 기본급을 같은 지표로 취급하지 않는다.
- 공식 자료, 언론/급여 데이터 업체 추정, 합계/기본급 자료의 범위를 구분한다.

### 일본: 성인 최저 급여 반영 필요

현재 모델 JPN 하한 EUR 19,000 × 고정 FX 160 = JPY 3,040,000.
J1 기본보수 하한 JPY 4,800,000을 보장하지 못한다.
JFA 2025-07-17 개정 안내에서 하한 적용은 2026-07-01부터다.
18세 이하 예외 등 적용 조건도 별도로 구분해야 한다.

2025 J1 민간 추정 자료는 평균 JPY 31,880,000, 최고 오사코 JPY 330,000,000이다.
모델 JPN 상한 JPY 320,000,000은 비슷한 규모이나 평균/최저/분포까지 검증한 결과는 아니다.

### 미국: 최고 연봉자 구간 부족

MLSPA 2026-04-16 기준 공식 자료: 메시 기본급 USD 25,000,000,
보장보수 USD 28,333,333. 모델은 기본급만 계산하므로 앞의 값을 비교해야 한다.
현재 USA 상한 EUR 15,000,000은 ECB 2026-10-14 USD 1.1195/EUR로 USD 16,792,500이다.
초특급 선수와 일반 선수에 같은 상한/곡선을 적용하는 현 구조로는 실제 상위 구간을 표현하지 못한다.
신규/일반 선수 하한은 성인/리저브 구분과 공식 급여표를 기준으로 따로 맞춰야 한다.

## 보정 전에 추가로 필요한 작업

1. 리그별 실제 기본급 하한, 일반 선수 분포, 구단 핵심/최상위 사례를 기준 데이터로 고정.
2. 명성/경기력과 재정 규모를 분리. 가능하면 구단별 선수 급여 지출을 예산 구간의 근거로 사용.
3. OVR 한 점의 지수 곡선 대신 신인/로테이션/주전/핵심/예외적 슈퍼스타 구간을 연속 연결.
4. 기본급과 보너스를 혼합하지 않고, 하한 준수/상한 몰림/구단별 차이/노장 재계약을 검사.
5. 15개 리그 전체를 실제 자료로 검증했다고 표시하지 않는다. 나머지 리그는 추가 조사 필요.
6. 급여 체계 확정 전까지 운영 랭킹 카드 재계산/저장 금지.

이번 점검 중 운영 KV 데이터와 급여 계산 상수는 변경하지 않았다.
