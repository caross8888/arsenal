# 승부차기 미니게임 — 커리어 연결 구현

> 상태: **커리어 연결 구현 · 배포 전**. 사용자가 기존 배경 수준의 도트 그래픽, 터치 조준, 파워 조절 방식으로 순서대로 진행하도록 요청했다. 직접 슛이 실제 대표팀 토너먼트 승패에 영향을 주도록 연결했다. 운영 반영은 아직 하지 않았다. 아래 과거 기획은 이력으로 유지한다.

## 독립 플레이 목업 (2026-10-13)

- `mockups/penalty-shootout.html`: 골문 터치로 연속 좌표 조준, 타겟 표시. 슛 버튼을 길게 눌러 파워를 올리고 손을 떼면 발사한다. PC는 방향키·스페이스를 지원한다.
- 파워 게이지는 빨강→주황→노랑→초록→노랑→주황→빨강의 연속 그라데이션이다. 별도 초록 칸은 없다. 최적 파워에서 **80% 성공률**이며 멀어질수록 연속 곡선으로 낮아진다. 높은 곳·구석을 조준하면 파워 정확도가 더 필요하다. 실패는 파워 오차에 따라 일반 선방에서 약한 슛 캐치 또는 강한 슛 골대·골문 밖으로 점차 달라진다.
- 생성한 도트 경기장과 투명 골키퍼 준비·다이빙·캐치·점프 스프라이트를 `mockups/penalty-assets/`에 둔다. 공은 별도 렌더링하며 선방·골대 충돌 뒤 튕김, 골망 반응과 결과를 표시한다. 골망은 충격점 중심의 감쇠 변위를 사용하고 테두리는 고정한다. 사각형 영역을 통째로 옮기는 방식과 금색 원 효과는 제거했다. 좌우 다이빙은 같은 스프라이트를 반전해 사용한다.
- 한 선수의 반복 슛을 확인하는 목업이며, 실제 대회 결과·승부차기 순번·통산 기록을 바꾸지 않는다. 대회·선수·상대 표시는 예시다. 이 파일은 독립 테스트용이며, 실제 커리어 연결은 아래 절의 게임 화면에서 처리한다. 본경기 압축 중계도 `public/career/match-playback.js`로 연결했으며, `mockups/match-playback.html`에서 별도로 확인할 수 있다.

## 실제 화면 흐름

토너먼트 경기 하이라이트 → 경기 종료 점수·안내(약 0.9초) → 연장까지 동점이고 승부차기 대상이면 직접 PK → 다음 라운드 또는 우승·준우승·탈락 결과. 일반 A매치·조별리그에는 PK를 띄우지 않는다. 마지막 하이라이트는 경기장을 유지하고 종료 표시를 남긴다. 경기장 이미지 로딩 중 건너뛰기를 눌러도 정상 완료로 연결한다. PK 입력은 직접 조준·파워만 전송하며 자동 버튼은 없다. 승부차기 현황은 골대 화면 안쪽 좌측 상단에 양 팀명·현재 PK 득점·성공/실패/대기 점으로 표시한다. 아래 별도 줄은 제거했고 현황 표시가 조준 터치를 막지 않는다. 실제 결과 화면에는 PK 점수, 대회 출전·골·도움, 대표팀 반응과 클럽 복귀를 연결한다.

## 실제 커리어 연결

- 실제 게임 화면은 `public/career/penalty.html`, 도트 자산은 `public/img/career-penalty/`를 사용한다. 본경기 도트 중계를 먼저 보여준 뒤 독립 목업과 같은 골문 터치·파워 조절·골망 변위 연출로 이어진다. 클럽 대회 승부차기는 아직 연결하지 않는다.
- 대표팀 토너먼트에서 선수가 출전한 경기에만 직접 승부차기가 가능하다. 경기별 별도 시드로 승부차기 후보를 24% 확률로 정하고, 4번 키커까지 이미 결정된 승부차기는 제외한다. 내 선수는 5번 키커, 양 팀 동료·상대는 기본 76% 성공률. 동점이면 동료들의 서든데스를 계산한다.
- 서버와 게이지는 `public/career/penalty-rules.js`의 같은 확률 함수를 사용한다. 화면에는 예상 성공률만 표시하며(파워 수치는 내부 계산에만 사용), 0·100 파워는 성공률 0%, 최적 파워는 80%다. 조준 높이에 따라 최적 파워는 68~70%, 높은 곳·구석일수록 허용 오차가 부드럽게 줄어든다.
- 슛 방향·파워만 부모 화면을 통해 `/api/career?a=penalty`로 전송한다. 서버 `_career_shootout.js`가 성공·선방·실축을 판정한다. 클라이언트에서 승패를 보내거나 브라우저 난수로 실제 결과를 확정하지 않는다. 직접 조준·파워 입력으로만 차며 자동으로 차기 버튼은 없다.
- 첫 미확정 승부차기가 있으면 `phase=penalty`로 시즌 시작 상태·선택·이미 판정한 슛 입력을 암호화 토큰에 저장한다. 그동안 우승 수상·명성·병역 혜택·통산 기록은 확정하지 않고 공개 화면에는 임시 경기 기록만 전달한다. 다음 시즌·이적·은퇴는 허용하지 않는다.
- 같은 시작 상태와 선택에서 서버가 시즌을 다시 계산하므로 클럽 경기 기록·현재 시즌 성장은 유지된다. 승부차기 승패로 다음 상대와 진출 경로가 달라지며 대회 출전 기록은 실제 남은 경기 수에 맞춘다. 이미 진행한 일반 A매치나 이전 라운드의 개인 기록을 다른 경기로 재배분하지 않는다. 승부차기 득점은 개인 골에 포함하지 않는다.
- 모든 승부차기가 끝나면 실제 우승·메달을 기준으로 수상·명성·다음 시즌 성장 효과·발롱도르 평가·이적 제안·병역 혜택과 통산 기록을 한 번 확정한다. 아시안게임 금메달/올림픽 메달 요건과 뉴스·SNS·커뮤니티의 기존 기대 성적별 반응은 새 결과를 따른다.
- 경기 재생의 건너뛰기·동작 줄이기에서도 직접 승부차기에서는 멈춘다. 직접 조준하고 슛해야 진행한다. 중복 클릭을 막고 통신 오류 때 저장을 유지한 채 재시도한다. 저장된 토큰 재개 시 같은 미확정 킥을 다시 연다.
- 검증: `node scripts/test_career_shootout.mjs`(서버 입력·확률, 실제 진출·병역 변동, 기록·성장, 단계·재개·재시도·부상). 실제 API와 모바일/PC 브라우저에서 직접 누르기·떼기, 다음 경기·반응·시즌 결과, 네트워크 오류 재시도와 화면 이탈 확인.

## 과거 기획 이력

### 사용자 요청 원문 요지

- 1군 시즌 진행 중간에 가끔 이벤트로 승부차기 화면이 뜬다. 승부차기는 토너먼트에만 있으니 **가끔**, 라운드는 임의(예: 챔스 준결승 승부차기, 챔스 결승 승부차기).
- 골대가 보이고, **좌측 하단 방향키 · 우측 슈팅 키**.
- 방향키로 골대 방향을 정하고, 슈팅 키로 **강도**를 정해 찬다.
  - 너무 세면 빗나감, 너무 약하면 골키퍼가 막음.
  - 적정 강도여도 골키퍼가 막을 확률 **28%**.
  - 빗나가거나 골일 때 골키퍼는 다른 데로 뛰거나 가만히 있음(가운데로 안 찼을 때).

### 목업에서 정한 것(1차)

- 조준: 3×2 칸(좌·중·우 × 위·아래), 방향키로 이동. PC는 화살표 + 스페이스.
- 강도: 슈팅 키를 누르고 있으면 게이지가 오르내림(한 번 오르는 데 약 0.9초, 끝에서 다시 내려옴), 떼면 슈팅.
- 적정 구간: 아래쪽 55~82, 위쪽 60~78(좁음). 게이지에 초록 띠로 표시(표시 여부는 미정).
- 판정: 너무 셈 → MISS(위·가운데는 크로스바 위, 옆은 골대 밖) / 너무 약함 → SAVED(골키퍼가 그 방향) / 적정 → 28% SAVED, 72% GOAL(골키퍼가 반대로 뛰거나 가만히).
- 결과: GOAL!/SAVED/MISS + 이유 + 실제 강도·적정 구간, 위쪽 키커 점(성공 초록·실축 빨강, 내 차례 금색 테두리).

### 당시 미정 사항

1. **커리어 영향**: 연출만(추천 — 기록·팬 피드에만 남김) vs 명성 ± 등 반영. 반영하면 ① 시즌 결과를 서버가 미리 계산하는 구조라 다음 시즌 호출에 결과를 넘기는 API 변경이 필요하고 ② 클라이언트 판정이라 조작 가능 → 랭킹 영향 주의.
2. **기록과의 모순 방지**: 서버가 이미 "챔스 우승"으로 정한 시즌에 결승 승부차기를 실축하면 안 맞는다. 결과 문구는 "내 킥 성공/실축"까지만, 대회명은 그 시즌 실제 기록에 맞추기(챔스 안 나간 시즌엔 챔스 승부차기 X).
3. **빈도**: 1군 시즌 약 15~20%, 시즌당 최대 1번, 출전 적은 시즌(예: 10경기 미만) 제외.
4. **건너뛰기**: 시즌 진행 건너뛰기를 눌러도 승부차기에선 멈춤 + 승부차기 화면에 "넘기기"(자동 판정 약 70%).
5. **적정 구간 표시 여부**.

### 퀄리티 메모(보류 이유)

- 첫 목업은 골대·골키퍼·공을 단순 도형으로 그려 "구리다"는 평가. 다시 할 땐 다른 오버레이(발롱도르·월드컵 시상, 입단 인트로) 수준의 그림·연출이 필요 — 원근감 있는 골대·골망, 골키퍼 실루엣·다이빙 모션, 공 궤적(커브·스핀), 슛 순간 카메라 줌/흔들림, 관중·조명 등.
- 시즌 진행 오버레이(경기 기록·팬 피드) 위에 끼어드는 형태라, 그 틀과 톤을 맞춰야 한다.
