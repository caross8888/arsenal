`public/career/league-scenes.js`가 구단의 `nat`으로 배경과 리그 표시를 고른다. `crSfOpen()`은 기존 `crSfClub()`의 소속 구단 선택을 이용하므로 선수 국적·해외 임대·임대 거절·부상 단계 재개를 그대로 따른다. `crSfMatch()`에서 시즌 중 구단이 바뀌면 배경도 바꾼다. 카드·경기 기록·팬 반응은 기존 UI를 사용하며, 팬 반응은 밝은 잔디 위에서도 읽히도록 기존 경기 로그와 같은 어두운 패널색을 사용한다.

이미지는 `public/img/career-leagues/{국가코드 소문자}.webp`에 둔다. 1024×1536 원본을 같은 해상도의 WebP로 변환했고, 총 용량은 약 4MiB다. 현재 소속 리그 한 장만 불러온다. 국가 정보가 없거나 이미지 로딩에 실패하면 기존 시즌 배경으로 진행한다. 빠르게 리그가 바뀌어도 이전 이미지 로딩이 새 선택을 덮지 않는다.

생성 원본 목록·주제는 [data/league-backgrounds.json](data/league-backgrounds.json)에 있다. 원본 PNG는 `/workspace/generated_images/`에 보존한다. 다시 변환할 때는 `python3 scripts/import_career_league_scenes.py --source-dir /workspace/generated_images`를 사용하고, 한 국가만 변환하려면 `--nation ENG`처럼 지정한다(Pillow 필요). 같은 이미지를 교체하면 `league-scenes.js`의 URL 버전과 `index.html`의 스크립트 버전도 올린다.

확인한 항목: 실제 페이지의 15개 리그·소속과 선수 국적이 다른 경우·해외 임대/거절·부상 재개·시즌 중 복귀·빠른 전환·이미지 실패 시 진행·모바일/PC 화면.
